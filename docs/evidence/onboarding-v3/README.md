# Captures de la maquette exécutable V3

Les 34 PNG d'écrans montrent chaque écran Simple et Atomique à 390 × 844 px, panneau compact puis déployé. `atomic-cover-overlay.png` montre la couverture derrière l'avatar, le nom et les liens. Ils sont produits par `tests/MeStudio/onboarding-v3-visual-test.js` à partir des contrôles PHP V3 et des feuilles CSS du dépôt. Les noms suivent `<mode>-<étape>-<état>.png` ; `atomic-v3_success` est la confirmation unique après publication.

Le banc vérifie aussi les largeurs 320, 375, 430 et 768 px dans Chromium et WebKit : débordement horizontal, téléphone unique, panneau compact non défilant, panneau déployé défilant, action visible et absence d'exception JavaScript. L'avatar, les liens de la carte et les médias de réseaux sont synthétiques ; les PNG ne prouvent ni le rendu du renderer Link branché sur WordPress, ni l'upload, ni la publication réelle. La comparaison de l'aperçu avec le profil public, le shortcode et Elementor doit être faite sur staging avec les médias officiels du catalogue Link.
