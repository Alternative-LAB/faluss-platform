# Captures du premier lot Fans UI V2

Captures Chrome local du 28 septembre 2026, largeur 1440 px et viewport mobile
390 × 844 px. Le serveur de recette utilise seulement des UUID synthétiques et
des profils structurés de test ; aucune personne, photo, somme ou session de la
planche n'est publiée. Le rendu n'est pas une recette WordPress réelle.

Écarts visuels et fonctionnels assumés avec les planches : aucun portrait ni nom
éditorial, aucune session, rang, score ou somme, aucune publication illustrée,
conversation, réservation ou produit réel. La bannière est une texture CSS ;
les cartes utilisent un motif abstrait. Les écrans encore sans moteur affichent
un état fermé. La sidebar Créateur V2 et les quatre destinations de gestion sont
présentes, mais seul Explorer → profil public lit une API existante dans ce lot.
